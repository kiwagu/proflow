# Shared Edge Function assets

## `notifications.bundle.mjs`

This file is generated by the workspace package `@workspace/notifications`:

```bash
bun run --cwd packages/notifications build:deno
```

Or from the repository root:

```bash
bun run notifications:bundle
```

The GoTrue `send_email` hook handler (`email_sender`) imports this bundle. Regenerate it after changing React Email templates or GoTrue mapping logic.
